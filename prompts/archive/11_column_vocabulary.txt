# Spire prompt set — 11 COLUMN VOCABULARY. Read by scripts/run_prompt_set.py.
#
# PURPOSE: the Phase 2A instrument. Measures whether a column named in a
# prompt reaches the output — across canonical names, formatting variants,
# plain-English synonyms, Oracle jargon, EBS-era vocabulary, and terms that
# should NOT resolve.
#
# This is NOT 04_columns (does the projection feature work) or 07_alacarte
# (does the projected table regress). Both of those name columns the KG
# already holds. This set names columns the way users actually do.
#
# ─────────────────────────────────────────────────────────────────────
# EXPECTED-OUTCOME LABELS — every prompt carries one
#
#   BASELINE   works today; must never regress
#   ANSWER     must return the named columns, populated, in order
#   DISCLOSE   must NAME the unresolved or substituted term back to the
#              user. A clean table with the term silently missing is a
#              FAIL, not a pass
#   REFUSE     must refuse; a silent near-miss answer is the worst outcome
#
# A second marker records what happens TODAY where it has been measured:
#
#   [MEASURED 07-31: ...]   observed, in t_fields.txt
#   [UNMEASURED]            expectation only — do not report as a finding
#
# ─────────────────────────────────────────────────────────────────────
# HOW TO SCORE — the summary line proves nothing
#
# For every prompt, three questions:
#   1. Does the Intent carry the term in `fields`, in `include`, or
#      nowhere at all? (--show-parser)
#   2. Does the printed table show it?
#   3. If not — DOES THE OUTPUT SAY SO? That is COL-03, and it is the
#      whole point of this set. Score it separately from 1 and 2.
#
# A prompt can "run cleanly", print a well-formed table, and still be a
# total failure of this set. Two of the five measured prompts on 07-31
# did exactly that.
#
# Run with:
#   python scripts/run_prompt_set.py --prompt-file \
#     scripts/prompts/11_column_vocabulary.txt --show-parser 2>&1 | tee t.txt
#
# ─────────────────────────────────────────────────────────────────────
# ANCHORS
#   Supplier 1252 = Lee Supplies (US, ACTIVE, 25 addresses)
#   Supplier 1262 = EIP Inc
#   PO 2144 = OrderNumber 162352, EIP Inc, 2 lines
#   PO 162034 = Lee Supplies, Closed, has invoices
#   Customer "ABC Application Software" = AccountNumber 26360
#   AR invoice CustomerTransactionId 300000248096352
#
# THE FIELD CATALOG IS SMALL. Read this before scoring:
#   Supplier has FOUR fields — Supplier, Status, SupplierId, SupplierNumber
#   Site has ZERO field rows
#   CreatedBy exists NOWHERE in kg_entity_field
#   CreationDate is a FILTER only, never projectable
# Several prompts below therefore cannot pass until COL-01 lands. They
# are here to be DISCLOSED, not answered.
