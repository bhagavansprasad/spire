# ============================================================
# Diagnostic prompt set — QA date/superlative/AR-parity failures
# ============================================================
#
# Source: QA sheet (86 prompts). This file selects and regroups the
# failures and their near-identical working siblings, so one promptkit
# run produces both the failing prompt and the control in the same log.
#
# Layout: groups are delimited by a `# === Group N — ... ===` comment
# followed by a one-line description of the delta being tested. Each
# prompt is preceded by a `# QA row N` comment naming its provenance.
#
# Each prompt appears exactly once, in the group whose working sibling
# best isolates its failure mode. Cross-group prompts (e.g. "recent AR
# invoices" is both "superlative" and "AR parity") are placed in AR
# parity, because that group's control (the PO equivalent) is the
# sharper delta.
#
# Run:
#   python scripts/promptkit.py --run \
#     --prompt-file prompts/diagnostics/date_qa_grouping.txt \
#     > t_date_qa_run_1.txt 2>&1
#
# Per WORKING_STYLE §15.1: capture the COMPLETE stdout+stderr to a
# file, then grep/sed from the file. Do NOT pipe through a filter at
# capture time.
#
# ============================================================


# === Group 1 — Relative day windows (last N days / yesterday) ===
# Delta tested: "last N months" works (QA row 5); "last N days" does
# not (QA rows 1, 2, 4). The parser/sysprompt teaches a months-based
# window, and the intent-validator may reject a days-based window the
# same way it rejects "0 months". Group includes the working months
# control so the run reproduces both sides in one pass.

# QA row 1
Give the suppliers which are created in last 30 days
# QA row 2
Show the new suppliers created within last 30 days
# QA row 4
purchase orders created in the last 7 days
# QA row 22
How many purchase orders were created yesterday?
# QA row 43
invoices in the last 0 months
# QA row 43 (sibling — "0 months" on suppliers)
suppliers with no invoices in the last 0 months
# QA row 44
purchase orders updated in the last 0 months
# CONTROL (QA row 5) — this one works
purchase orders in the last 6 months
